# 例子背景句：理解原理与实现代码

本条是同一引导练习中的填句回答，不是新增独立作文。题目来源及完整中文翻译见父记录和起始记录20261122_2323_issue.md。用户未提供实际用时，不能用聊天间隔推算。

## 用户原答

```text
understand how to code a stack successfully
```

前置句框由教练提供：For example, when I was tutoring a student in programming, he struggled to ______.

## 定性反馈

- position：未新增立场。
- development：开始把中文家教例子转成英文，但code a stack successfully表达成功编程实现一个栈，与原中文“不理解栈的原理、不能完整记录出入栈过程”不完全一致。不能擅自认定学生曾写栈实现代码。
- organization：本轮只是背景句后半部分。
- language_control：struggled to understand how to code...结构成立，不把how to或code判为语法错误。若沿用此前的“理解原理”，understand how a stack works更贴切。
- task_fulfillment：当前仍为分步、有提示练习，尚未写完整例子、论点联系与边界分析。不评分、不新增完成事件或mastery升级。

这里保留用户原话，并将调整标明为基于原中文的语义对齐，而非强制的语法订正。若用户后续确认实际困难确实是实现代码，再据事实调整。

## 教练目标表达（尚非用户修订）

> For example, when I was tutoring a student in programming, he struggled to understand how a stack works.

中文：例如，我辅导一名学生学习编程时，他难以理解栈的工作原理。

how a stack works表示栈如何运作；间接问句使用主语在前、动词在后的语序。a stack为单数，work用works。这里一般现在时描述一般原理，可以出现在过去经历中。

## 下一句：比较两种做法

中文目标：我发现，直接给他看正确答案，不如只提供必要步骤有效。

教练句框：I found that showing him the correct answer was less effective than ______.

词语提示：provide表示提供；only the essential steps表示仅必要步骤。此处比较showing与providing两种做法，用平行形式；不是说than后在所有情况下都必须用-ing。
