# 手机端可行方案

核查日期：2026-09-19，Asia/Shanghai。状态：研究建议，未部署。

## 建议

长期采用手机适配的 PWA 加一个常在线私有后端。先做在线版本，再添加离线背词。若只想尽快试用，先用 Tailscale Serve 连接当前电脑，验证真实手机操作。

PWA 是网页的安装和运行方式，不决定后端位置，也不自动提供离线保存能力。

## 当前架构证据

- platform/server/index.mjs 只监听 127.0.0.1，并限制 Host 和 Origin 为 localhost；现状不能直接从手机访问电脑局域网 IP，也不能直接挂隧道而忽略访问校验。
- React 界面已有小屏样式，但尚未做本次手机真机验收。
- 服务端从文件读取词库、资料和追加事件。手机不需要运行 Git 或 Node。
- 草稿主要保存在浏览器 localStorage，换设备不会自动带过去。现有少量失败重试缓存不等于完整离线模式。
- AI 讲解依赖电脑上的 Codex CLI 登录；迁移网页不自动迁移 AI 运行环境。
- 题中摘词依赖选择文本后右键，需要改成长按选择后点击收录按钮。

## 方案对比

| 方案 | 电脑关机后 | 外出使用 | 改造规模 | 费用与维护 |
|---|---|---|---|---|
| 同一 Wi-Fi 内访问电脑 | 不可用 | 默认不可用 | 小 | 无新增云主机费；管理电脑启动和局域网访问 |
| Tailscale Serve 私有访问电脑 | 不可用 | 可用，需两端联网及连接私有网络 | 小至中 | 需核对账户套餐；仍依赖电脑在线 |
| 常在线服务器 + PWA | 基础学习可用 | 可用 | 中 | 主机、存储、备份，域名可选；具体报价待选地区和服务商 |
| 原生 App 或小程序 | 取决于后端和离线实现 | 可用 | 大 | 额外客户端、发布与适配维护，仍需解决后端 |

Cloudflare Tunnel + Access 可作为不要求手机安装私网客户端的远程入口替代方案；隧道不会消除电脑关机问题。实际访问质量需在用户 Wi-Fi 和蜂窝网络测试。

## 推荐实施顺序

1. 在线手机版：常在线 Node 服务、持久数据卷、HTTPS 和私人登录；沿用事件结构，提供手机首页、今日复习、词库和题目导航。固定允许的域名与来源，不直接取消 Host/Origin 校验。资料按权限访问。
2. 共用数据：手机和电脑连接同一个后端。服务端串行接收事件，按事件 ID 去重；GitHub 用作版本归档与备份，页面显示保存和备份状态。教练导入也经过同一写入流程，避免服务器与本地工作副本同时修改数据。不要把 Git 凭据放进手机网页。
3. PWA 与触控：添加 manifest、图标、主屏入口；长按选词后出现收录按钮；适配软键盘、拼写禁用自动纠错、底部操作区、PDF 缩放与长文章。数学图表需单独真机验收。
4. 离线背词：显式下载词表或一轮任务，IndexedDB 保存轮次和待上传事件，联网及再次打开页面时重试。不要依赖手机后台一定运行。规则需处理两端同时练同一轮、重复结算、跨日时区和旧快照冲突；只缓存页面不能算离线学习完成。
5. AI：先保留已保存的讲解。新讲解可继续交给电脑上的受控任务服务，电脑离线时明确不可用；若要求全天可用，再单独评估服务器 AI 运行方式和计费，不默认现有桌面订阅或凭据可直接搬到云端。

## 验收标准

- iPhone Safari / Android Chrome 真机完成一轮四阶段复习；后台切换后可恢复，软键盘不遮挡提交按钮。
- 手机保存后电脑可看到同一条记录；重复请求不增加复习次数。
- 新版手机摘词能保存单词、题目位置和短语境，不误选答案。
- 云端方案下关电脑仍可背词、做题、查询记录；新 AI 讲解的可用性单独展示。
- 第二阶段离线模式：飞行模式完成下载的词汇轮次，联网后只同步一次，不抹去首次错误，不重复结算。
- 未登录不能读取或修改题目、PDF 和学习记录；完成一次备份恢复演练。

## 待用户选择

手机是 iPhone 还是 Android；是否必须电脑关机也能用；是否需要地铁等无网场景；是否接受持续主机费用。未选择前不购买、不部署外部服务。
