# 手机 ChatGPT 登录与首次解析

1. 覆盖安装最新版 APK，保留旧应用及其数据；不要先卸载。
2. 打开“设置 → AI 题目解析 → Continue with ChatGPT”。
3. 在系统浏览器登录已有订阅的账号，检查应用名称及请求权限后完成授权。
4. 浏览器收到回调后，点击“返回 GRE词库”，或使用最近任务切回 APP。回调提示只代表手机收到结果，尚不代表身份及计划权限已通过。
5. APP 会依次显示等待浏览器、交换授权、校验身份等阶段。账号验证成功即显示账号；可用模型单独加载。模型加载失败可点“重新加载模型”，不必先退出账号。
6. 在“解析模型”选择可用模型，进入刷题，打开一题已有提交记录，点击“解析本题”。
7. 检查完整题干翻译、原顺序全部选项及推理依据。结果通过格式校验后保存为暂定 AI 讲解，不改原作答或参考答案。

回调后不能无限显示“请在浏览器完成授权”。修复版提供阶段、超时、取消与重试；失败时记录界面显示的阶段和错误文字即可，不发送密码、验证码或完整回调 URL。

收到回调后，交换授权与身份校验共享60秒时限。账号出现后，模型加载单独限时35秒；失败可单独重新加载模型。界面状态读取也有超时，必要时点击“重新检查状态”。若浏览器登录太久，等待回调超过4分钟后需要重新授权。

AI 需要手机本身能联网及账号授予计划使用权限。浏览器能登录，不等于 APP 的后续网络请求或账号推理权限已验证；实际额度和模型可用性以服务返回为准。不会自动使用收费 API。

2026-10-28 真机反馈：0.3.0 已到“已收到授权回调”，切回 APP 后仍显示“请在浏览器完成授权…”，没有错误、账号或模型。此反馈只证实回调已到，不作为订阅推理成功的证据。0.3.1 针对此等待流程修复，真实账号解析仍需安装后验收。

## 授权网页的允许按钮持续转圈

2026-10-28 后续截图停在 OpenAI 托管的“允许智能体访问”页面，允许按钮转圈；用户说明使用手机默认浏览器，具体名称与本次安装版本尚未确认。截图本身不能证明回调已送达，也不能据此判断浏览器故障或订阅不支持。

先切回 APP 检查实际阶段：已出现账号则继续加载模型；等待浏览器表示尚未接受有效回调；超过4分钟或显示回调超时则取消本次登录。APP 使用系统默认浏览器，未固定浏览器包。可临时选用已有 Chrome 或 Edge 作为默认浏览器，关闭旧授权页，再从 GRE 发起一次全新授权作对照。

不要刷新、复制或复用旧授权链接来重试，旧链接绑定旧的状态和本机监听端口。观察新流程是否出现回调页及 APP 阶段即可，不收集完整授权 URL。当前参数已按官方注册文档核对；没有证据支持为此盲目更改权限、回调地址或重新打包。

## 换浏览器仍转圈：0.3.2兼容验证与诊断

用户继续反馈换浏览器后仍卡同一授权页面，单纯更换浏览器未解决问题。进一步核对发现官方说明与官方 DevKit 默认行为不一致：说明将 `ext_agent_host_id` 写为必需；DevKit 的 `sendHostId` 配置默认 false，且说明只有兼容的授权部署才应启用，官方示例也未启用。0.3.2采用该 SDK 默认参数，保留本机稳定 host ID，不改变 PKCE、state、nonce、签名、账号绑定和计划权限检查。此改动是有来源依据的兼容性验证，不代表已确认手机故障根因。

源码依据：DevKit revision `0a36fefeb913055c8c7a1a29b63d82b96b2e841a`，`packages/local/src/types.ts` 的 `sendHostId` 注释、`oauth.ts` 的条件发送，以及官方 Paste Perfect 入口。官方回调本身也只接受 GET，并无 CORS/OPTIONS 处理，因此没有凭假设放宽本机回调策略。

覆盖安装0.3.2后，设置页应显示版本号。重新发起一次授权；若同页继续转圈约20–30秒，切回 APP，**先不要取消登录**，点击“复制连接诊断”并将文字交给 Codex。无法自动复制时，界面会显示可手动选中的净化文本。

诊断只保留版本、授权模式、阶段、等待时间、监听是否开放、所有本机请求行计数、是否收到有效回调及最近拒绝原因枚举；不含账号、host ID、URL、state、授权码或令牌。`status_source: live` 表示刚读取成功，`last_known` 表示读取失败后保留的上次状态，不能冒充当前现场。有效回调也可能包含授权拒绝，最终是否连接仍以阶段与账号状态为准。
