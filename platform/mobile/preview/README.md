# 手机刷题交互预览

2026-10-20：用户要求先审核前端，再决定正式开发。独立入口，不载入 App、repository、IndexedDB 或原生存储；选择与确认只存在 React 内存，刷新丢弃。没有答案、判分、AI 讲解、写作或 APK 改动。正式 App 默认仍为三个底部入口。

从仓库根目录准备并运行：

```powershell
node platform/mobile/scripts/prepare-practice-preview.mjs
npm --prefix platform/mobile run preview:practice
```

打开 http://127.0.0.1:4175/ 。样题只读取现有本地 PDF 索引：六选二三题、填空单/双/三空各一题、阅读三题、数学数量比较三题。数学保持原 PDF 排版。样本正文与图片只生成到忽略的 `samples.local.json`，不纳入 Git，不复制答案或用户作答。需先通过电脑平台生成现有题库索引；缺资料时脚本报错，不自编替代题。

预览范围：四类入口、开始练习、选择/取消、每空单选、确认选择/修改、上一题/跳过/下一题/目录。数学暂以数量比较展示布局，其余数学作答方式待本轮视觉反馈后设计。旧导航页只提示沿用现有版本，不伪造学习数据。

2026-10-21 用户反馈：阅读改为上下分屏，原文在上、题目在下，两侧独立滚动。默认原文占可用高度42%；拖动中间分隔条调整，键盘上下键每次5%，Home/End调至边界，双击恢复默认。通常每侧至少140px，极矮视口按剩余空间等比例收紧；旋转或窗口变化重新约束比例。A−/A＋同步调整原文、题干、选项字号（15–22px），不隐藏任何一侧。同篇文章切题保留原文滚动位置。比例与字号只在本次预览内存保留。

此目录与预览脚本不进入正式 Vite 构建入口。独立检查：

```powershell
npm --prefix platform/mobile exec -- vite build --config preview/vite.config.js
```
