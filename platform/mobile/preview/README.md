# 手机刷题交互预览

2026-10-21：独立前端预览，不加载正式 App、repository、IndexedDB 或 Android 存储。当前选择、确认、分屏比例与字号只在 React 内存中保留，刷新丢弃。没有写作、判分、AI 讲解、写入作答或 APK 改动；正式 App 仍为三个底部入口。

从仓库根目录准备并运行：

```powershell
node platform/mobile/scripts/prepare-practice-preview.mjs
npm --prefix platform/mobile run preview:practice
```

打开 http://127.0.0.1:4175/ 。准备脚本只验证已有本地题库索引，不再抽取三道样题、不复制全文、不批量生成图片。首次请求只读取轻量目录，选题后读取具体正文；数学与不能安全重排的题目按需渲染原 PDF。缺少缓存或原书时报错，不自编替代题。

右上角“题目导航”支持六选二、填空、阅读、数学切换，按教材/单元/原书题号访问每一个已索引题位。单元可搜索，题号可直接输入；题号超过一页时每页最多60个。目录区分已提交、同内容已做、当前草稿与预览确认；提供全部/已提交/未做过/草稿筛选，手动刷新电脑记录。2026-10-21 本地可读3742题位：SE1001、TC1001、RC893、Quant847，不以教材标题数字冒充全部已抽取题数。

只读历史从原始 `attempt`/`attempts_import` 及有证据的旧训练记录派生。旧训练与平台记录不叠加为额外次数；历史时间按时间戳比较。历史作答按当前题位独立显示，同内容已做不会伪造本题提交。已做题默认只读，显式“预览重做”后可在内存里试答；当前预览不产生新的历史。旧答案在预览重做未确认时隐藏。不读取或展示标准答案和 AI 讲解。

阅读原文在上、题目在下，分别滚动。默认原文占可用高度42%；拖动横条调整，键盘上下键每次5%，Home/End调至边界，双击恢复。通常每侧至少140px；极矮视口等比例收紧，视口变化重新约束。A−/A＋同步调整原文、题干、选项字号（15–22px），原 PDF 区域同比例缩放。同篇文章切题、切底部页后返回保留原文位置；图片预留原尺寸比例，加载完成再恢复位置。

支持单选、六选二、多选、每空单选、原文选句和数字输入的交互。解析不完整的题目保留 PDF；数学原页用淡色侧边标示当前题的文字区域，但保持整页以免裁掉图表。没有可靠选项标签的数学题采用“按原题填写答案”，不猜选项数。缺可核实句子文本的选句题只读且不能确认。

预览 API 只允许本机同源 GET，不提供事件写入路径，不调用可重建题库索引的生产接口。图片串行渲染，内存最多缓存24张；不会打包全库 PDF 或题干。开发与 Vite preview 均需要本地服务，构建出的静态目录单独打开不能读取本地题库。

验证（工作目录 `platform/mobile`）：

```powershell
node --test preview/navigation.test.mjs
npm exec -- vite build --config preview/vite.config.js
```

本轮没有浏览器交互验收：之前的浏览器访问限制仍有效。模块测试/本地渲染检查不替代实际手机显示与触摸体验。
