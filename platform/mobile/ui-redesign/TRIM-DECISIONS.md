# 功能裁剪与全页改版决定

依据 `FEATURE-AUDIT.md`（2026-11-22）。Claude 审定，用户确认后交 Codex 执行。

原则：每页只有一个最显眼的下一步，其余收进二级或删掉。**只删界面入口和文案，不删数据、事件和 repository 接口**；旧数据照常读取和排序。

## 一、三条产品取舍（用户已于 2026-11-22 确认，按下文执行）

1. **「记录本轮卡片状态」改为自动，按钮删掉。** App 退到后台时、或打开时发现草稿属于前一个学习日时，自动调用原来的记录流程；没有新翻阅也没有新标记时不写。写入失败时草稿保留，下次再记，不弹错误。变化只在于词墙「一轮」何时结束（从手动变成自动），「本轮改标不重复计次」的规则不变。理由：这个按钮要用户记得去按，实际上几乎不会被按，翻阅记录就一直停在草稿里。
2. **底栏「复习」改名「背词」。** 「复习」和「刷题」新用户分不清（盘点里的结论）；「背词」一眼就知道是单词，「刷题」是 GRE 原题。
3. **深色从「词墙配色」改为全局「外观」：浅色 / 深色 / 跟随系统，默认跟随系统。** 现在只有词墙会变深，切到别的页面是浅色，不统一。

## 二、词库

删：
- 菜单「记录本轮卡片状态」（见一.1），以及菜单底部的说明「本轮改标不重复计次…」。
- 菜单「清空选择」：「取消」已经能退出多选，要重选就取消后再进。
- 菜单「查看所选词详情」：长按条和翻面角标都能进详情。
- 菜单里的手势说明：移到设置「帮助」。第一次进词墙时给一条一次性的手势提示，看过后不再出现。

合并：
- 「撤销后移」和「撤销上次标记」合成一个「撤销」，行为和双指下滑一致：撤销最近一次（标记或 Fresh）。没有可撤销的动作时不显示。
- 「背诵筛选词」和「为当前选中单词设置复习轮」合成一个「复习这些词 · N 词」。多选时用所选词，否则用当前结果里有释义的词。两条入口打开同一张表：词数、认义遍数（1 或 2）；底部主按钮「现在开始」（走原来的自由会话），次按钮「存为一轮」（展开名称输入，走原来的 createReviewRound）。两条写入路径都不变。

改名：「补充整理」改为「标为待整理」；「为当前多选单词分组」改为「分组」；「fresh 本页」改为「Fresh 本页」。

改完后的菜单：
- 未多选：Fresh 本页 · 复习这些词 · 撤销（有可撤销时）
- 多选中：复习所选词 · 分组 · 标为待整理 · 选全部结果

筛选弹层：常用的放上面（记忆状态、排序、关系或分组），主题、首字母、来源收进「更多条件」，默认折叠。

词条详情：首屏只放单词、音标和发音、词性与释义、第一条例句、三档标记；其他义项、关联词、复习次数与翻阅时间、词义说明和来源收进「更多」。「编辑」放右上角。

清理死代码：SizeSheet 及其导出；App 里已没有调用方的带撤销提示分支（先确认确实无人调用）；practice.css 的 `.directory-history`；native.js 中未被调用的导出。repository 里的 `startQuickRound` 不动。

## 三、背词（原「复习」）

首页只留：
- 标题行：「今天 N 轮」（N 是逾期加今天未完成的轮数；为 0 时写「今天没有要背的」）。右上「⋯」：新建每日计划、管理计划。
- 待背列表：顺序沿用现有的 `orderedReviewRounds`（置顶、逾期、今天、其他）。一行一轮：名称、词数、进度线、到期标签（逾期或今天）。行尾「⋯」和长按都打开同一个菜单：改名、置顶、删除本轮、查看所属计划。
- 「已完成 N 轮」一行，点开后展开列表，每次渲染 20 条，滚动时再加载。
- 底部固定主按钮「继续 · 轮名」，指向列表第一条未完成的轮。没有未完成的轮时，换成幽灵按钮「新建每日计划」。

删：眉题「按自己的节奏」、副标题「从保存的步骤继续，让每一轮都有着落」、「长按卡片管理轮次…」提示、「从单词墙选词」链接（底栏已能回词库）、「复习步骤与颜色」说明块（规则压成一句，放进新建计划表单底部）、状态下拉框、每页四轮的分页。

术语统一：「复习任务」改称「每日计划」，「轮次」改称「一轮」。轮菜单里的「调整所属任务」「取消后续任务」换成「查看所属计划」，到计划页里再调整或停止。

新建或调整计划的表单：名称、每天几个词、截止日期放上面；主题和关系筛选收进一行「范围」，点开再选。

背词会话（全屏）：所有阶段、判定、保存顺序、续接和退出保护照旧。视觉按候选 C：
- 顶部一条进度。主进度是已结算词数除以总词数；当前阶段用文字标注，例如「认义 1/2」「补全」「默写」。
- 题面居中、大字号。
- 主操作固定在拇指区。反馈不遮挡按钮。软键盘弹出时，主按钮停在键盘上方。

## 四、刷题

- 首页：题型改为顶部四段切换（SE / TC / RC / Quant），下面一行库存（已做 / 总数），再加一个主按钮，有草稿时写「继续作答」，否则写「开始」。右上只留一个「目录」入口。删去重复的「按单元选题」、重复的题型标题，题型说明压到一句以内。
- 目录弹层：保留单元搜索、题号跳转、状态筛选和题号网格。状态词缩短为已做、未做、草稿。
- 作答页：所有题型控件、RC 双区与分隔条、选句、长按选词、原图放大都保留。A− / A+ 收进 RC 原文区右上角的「Aa」小菜单。长按选词的说明只在第一次出现。
- AI 解析：已连接且正常时，只显示「解析」按钮和结果。套餐和资格信息只在出问题时出现，并附「去设置」。
- 上一题 / 下一题的固定栏变矮，可点区域不小于 44 px。

## 五、设置

分四组：
1. **外观与声音**：外观（浅色 / 深色 / 跟随系统，全局生效）、记忆状态（圆点 / 填色）、词墙方向、英文字号上限、音效、翻页音色（选中时试听一次）、触感。
2. **数据与备份**：导出 / 恢复词汇备份、导入词库、导出 / 导入刷题记录。「恢复工具」一行收纳词库更新前备份、恢复前备份、撤回上次恢复，只有存在相应快照时才显示。
3. **AI 解析**：一行显示状态（「已连接 · 模型名」或「未连接」），点进二级页再操作：连接或重新授权、选模型、管理额度、退出、重新检查、复制诊断。
4. **帮助**：手势、离线使用与数据说明、学习日时区（只读）。

主屏上的长段说明全部移进「帮助」。

## 六、四页统一的视觉规则（以 `prototype/src/c/c.css` 为准）

- 颜色、字体、圆角、间距一律用候选 C 的变量。把 `wall-candidate.css` 里的 `--c-*` 变量提到应用根部，四页共用，深色用同一套。
- 英文单词和英文题面用 Source Serif 4，其余界面用系统无衬线字体。
- 每页最多一个实心主按钮，次级动作用文字按钮或幽灵按钮。红色只出现在危险操作的确认里。
- 列表用整行样式（参照 C 的 `.rows`），不用一张张带阴影的卡片。
- 弹层统一用 C 的 sheet。
- 文案只写用户要做的事和结果；删掉口号、鼓励语和重复的解释。

## 七、不许动

repository 和事件模型；Fresh 的逻辑和作用域；复习轮次契约和每日生成规则；题库加载和校验；练习计数、排期、草稿和提交；AI 请求和结果校验；翻面草稿的内容（只改提交时机，前提是一.1 获批）。标记一律走 `rate()` 和 `undoQuickReview()`，没有释义的词照旧不能标记。
