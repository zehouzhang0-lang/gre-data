# 单词墙首阶段原型 · 设计规格

2026-11-22。只使用合成词条状态和演示进度，与正式 App 数据隔离。图像概念使用内置 Image Gen 生成，参考为 `concept.png`；尚未由用户选定最终方向。

推荐 A 清爽白底作为第一轮生产候选。保留熟悉的四列与青绿，改动集中在层级和反馈，方便与现状对照。B 纸感阅读保留相同信息和功能，用于比较长时间阅读舒适度。

| 规则 | A 清爽白底 | B 纸感阅读 |
| --- | --- | --- |
| 画布/正文/主色 | #ffffff / #173c39 / #137b71 | #faf6ee / #293c35 / #486853 |
| 记忆色 | 忘记 #f1d1c9；部分 #f7e6b5；清楚 #cfe8d8 | 保留相同语义，用略暖色温 |
| 字体 | 系统中文；Trebuchet MS 英文 | 系统中文；Georgia 英文 |
| 卡片 | 12px 圆角，4列7行，6px 间距 | 7px 圆角，相同密度 |
| 字号 | 标题28px；英文14px；界面13px；辅助11px | 英文15px，其余一致 |
| 图标 | Lucide 20px / 1.7px 描边 | 同 A |

可见首屏内容：词库；随时认识，新鲜的一页；多选；搜索单词、释义或笔记；全部单词；演示顺序；三档记忆色图例；28词；上一页/下一页；页码/总词数；fresh 本页；双指上滑，换一页新鲜词；词库/复习/刷题/设置。

概念图默认 A–Z 与未排序的示例矛盾，原型明确标为「演示顺序」，同时提供真正 A–Z 排序。原型去掉概念图重复 lucid/candid，用 robust/affable 替换，保持词条唯一；补上中性未标记词条的可读状态。以上为实现前明确的修正。

动作不等待动画：先提交新状态，然后对新内容做有方向的 150–180ms 入场；不使用 setTimeout 延迟查询。搜索保持输入焦点，不做整页入场。前后翻页±18px；Fresh 从下方12px换入，反馈当前批次后移位置；复习成功只对保存反馈做小幅淡入。减少动态效果时取消位移。

功能组件：Workbench（评审控制）→ Phone → Wall / Review / Practice / Settings；共用 Icons、Pager、Toast、主题令牌；纯函数处理分页/Fresh。示例数据模块预计算 searchText，原型使用独立 localStorage key。底部导航保持固定；窄屏或放大字体时内容可滚动，不截断操作。

原型范围：28词墙、行内查询/筛选/排序、翻面与多选、左右滑、Fresh按钮/双指上滑/撤销、搜索返回位置、演示复习轮续接和进度。刷题展示交互骨架与非题库的原创一句话样例，不调用 AI。设置展示主题和保存状态。所有测试状态入口放在评审区，不混入产品文案。
