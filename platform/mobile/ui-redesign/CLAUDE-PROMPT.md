## 项目上下文

- App 在 `platform/mobile/`，采用 React、Vite、Capacitor，常用功能离线可用。安卓分别用本地 SQLite 保存词汇和刷题数据，网页开发预览用 IndexedDB。React 页面入口是 `src/App.jsx`，设计变量在 `src/design-tokens.css`，共用界面在 `src/components/Primitives.jsx`。先读本目录的 [README](README.md) 和 [现状评审](REVIEW.md)，有仓库访问时按 README 的源码地图进入。
- 底部四个入口是词库、复习、刷题、设置。词墙默认四列，每页 28 词。轻触翻面，长按进入多选，左右滑翻页，单指纵向滚动。行内搜索可按现有筛选查看，清空后返回搜索前位置。fresh 本页让用户把已熟悉的当前页往同一浏览顺序后面挪，留在当前页看后续词。它有按钮及双指上滑入口，只改变浏览顺序。
- 复习按命名轮次继续，包含英文认义、补全拼写、中文默写，结束后按真实记录展示结果。刷题支持 SE、TC、RC 和 Quant，保留原题顺序和原题定位，可续接草稿。SE、TC、RC 支持左右切题，Quant 沿用按钮。阅读保留上下分屏与独立滚动，选词摘录也应正常工作。
- 三档记忆色来自用户自评。可以强化已保存的反馈、当前阶段、完成数量以及下一步，保留标签和非颜色辨识。练习计数、复习排期、个人词义、分组、隐藏状态、作答草稿和轮次断点沿用现有数据规则。
