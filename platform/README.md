# GRE 学习工作台

现有GRE数据的本地网页入口。React + Vite负责界面，Node负责读取仓库与追加记录；基础学习功能无需数据库或付费服务，可选AI使用本机Codex订阅额度。

## 使用

安装Node.js 22+和Git，克隆或拉取本仓库。Windows运行 `./start-platform.ps1`，macOS/Linux运行 `bash ./start-platform.sh`，打开 http://127.0.0.1:4173 。首次自动安装依赖，每次启动重新构建；设置PORT可更换端口。启动脚本不会弹出命令窗口。也可让项目内的 `$gre-platform` skill 启动。

- **刷题**：默认从已有填空2000、阅读440、数学900三份PDF自动定位题目。选择题型后点选答案、提交、继续；不需要输入页码、单元或题号。TC多空分组选择，SE选择两项，Reading自动关联文章，选句题直接点选句子。数学保留完整原页图表；无法提取选项的题目填写实际答案。草稿保存在当前浏览器，正式作答保存在仓库。无计时证据的作答保持未计时。
- **资料库**：默认接入materials/catalog.yaml中的全部10份PDF，可直接看、按页跳转、单独打开。新增PDF最大30MB，存入materials/uploads；用户主动上传的PDF会随同步提交GitHub。
- **题目与答案导入**：支持JSON；答案另支持TXT，每行 `题号 答案 | 解析`。先预览再确认。上传我的作答与标准答案分别选择，避免把自答误当答案。导入的标准答案统一标记user_provided。
- **生词本**：查询、新增、编辑、移除与恢复；原记录不会被删除。部分旧词只有名单没有独立释义，显示尚未整理，可在词条查看历史批改或补充。
- **回忆**：默认10词一轮，依次认义两遍、补全字母、中译英，错误穿插重练。每次练习保存，支持中断续练；不修改原主序停点或自动授予掌握等级。
- **历史**：先看学习日期目录，再按题目或单词聚合查询；整理操作单独保留。新作答、事件和既有Markdown训练均可查阅和导出。
- **AI讲解与复盘**：作答后点击“AI讲解这道题”；学习记录中也可打开已做题目，或在“AI复盘”汇总最近练习。系统自动读取题干、参考答案和原作答，不必复制粘贴。结果作为暂定分析单独保存并可同步，不覆盖原作答、参考答案或技巧掌握等级。

## AI连接

本机安装Codex CLI并通过 `codex login` 登录ChatGPT账号，`codex login status` 应显示 `Logged in using ChatGPT`。平台自动查找CLI；Windows也查找Codex桌面应用附带的可执行文件。已验证CLI 0.153.4。其他设备需在本机单独登录，登录凭据不会随仓库同步。

服务端调用官方 `codex exec`，复用ChatGPT登录和订阅额度；Pro的20x用量不等于API余额，API按量计费与订阅独立。此入口强制ChatGPT登录并移除API密钥环境变量，不会自动改用付费API。按用户2026-10-01的节省额度要求，模型默认gpt-5.6-terra，推理强度medium，不自动升级到sol或astra；可在启动前通过 `GRE_AI_MODEL` 改为账号支持的Codex模型。`/api/ai/status` 返回实际配置模型与推理强度；CLI不在默认路径时使用 `GRE_CODEX_BIN` 指向其可执行文件。

只有点击分析按钮才发起模型请求。同一时间运行一个分析，最长等待5分钟，可以停止；失败时保留已有作答。模型接收本次题目/必要原图区域和学习记录，使用只读临时目录、结构化输出，关闭命令执行、插件及多agent；由平台后端校验并追加结果。临时文件随后清理，不把凭据或CLI日志写入Git。近期复盘只读取最近20次作答和60条词汇自评，不凭自评推断正式成绩。

官方依据：[登录与计费方式](https://learn.chatgpt.com/docs/auth)、[非交互调用](https://learn.chatgpt.com/docs/non-interactive-mode)、[订阅用量](https://learn.chatgpt.com/docs/pricing)。

## 跨设备

点击“同步进度”：保存平台事件和主动上传的PDF → 拉取并rebase origin/main → 普通push HEAD:main → 页面自动读取新记录。只有事件和平台上传的PDF会被自动提交；其他修改必须先人工检查。冲突会保留现场并报错。换设备前同步，在另一设备pull并启动；不要两台同时写同一仓库。数据变化每5秒读取一次；代码更新后重新启动，依赖改变时启动脚本传 `--install`。浏览器草稿尚未提交，不随Git同步。

本机服务只监听127.0.0.1，并检查Host/Origin。手机尺寸可用；直接在手机上使用需另行配置访问，不会把本地服务自动暴露到公网。

Android 本机运行的分步提示词见 [手机项目接管、安装、训练与同步](mobile-prompts-20261006.md)。已核对代码与官方环境说明，尚未手机真机验收；ChatGPT 仓库连接和 Termux 本机运行需分别验证。

## 导入格式

每题最多保留必要题目片段或用户明确提供的题目，不自动复制整套题库。

```json
[
  {
    "material": "text_completion_2000",
    "unit": "test2_section1_easy",
    "question": "6",
    "type": "tc",
    "prompt": "填写实际题干",
    "options": [],
    "answer": null,
    "explanation": ""
  }
]
```

题型为tc/se/rc/quant。题目导入需要prompt；答案导入需要answer，省略prompt/options。答案和解析可后补，既有作答按最新答案重算显示，但原作答及历次答案事件不覆盖。TC多空按顺序，SE/RC/Quant多选按集合；数字支持十进制和简单分数；Reading选句键指定answer_format为sentence后比较完整句子；其他自由文字不自动判分。没有答案或无法可靠比较时result=null，不换算GRE量表分。

## 开发与迭代

### 写作训练（2026-10-19）

桌面平台侧栏“写作训练”只训练现行 Analyze an Issue；目标读取档案中的 AW 3.5，与 Verbal/Quant 分开。默认提纲训练，也可选择单段、整篇和 30 分钟限时实战。提纲/单段不是完整作文，未完成的全文也不估整体分；没有样本时不预设弱项。

首版内置 6 道明确标注的教练原创入门练习，每题保留完整英文题干、任务要求及中文译文，**不是 ETS 真题池**。页面提供 ETS 官方说明、题库获取入口和评分依据；“使用自己的题目”需要完整题干及随题要求，录入后仍标用户提供，不自动宣称已核验来源。同主题不同要求不按客观题去重。

开始后每次编辑保存到本浏览器 `gre-writing:v1:` 草稿；刷新或切换页面可继续。草稿不随 Git 同步，清除浏览器数据会丢失未提交内容，重要稿件可导出文本。保存失败显示警告，冻结提交可使用同一编号重试；只在服务端确认后显示已保存。开始练习仅记录会话，不计为已完成作文。

限时练习按服务端开始时间确定绝对截止时间；刷新/离页不重新计时，截止冻结当时已有文本。禁止平台提示与拼写检查；这仍是非监考练习，不保证阻止外部辅助。到时按用户全文完成声明提交；空白不生成作文或分数。断网/关闭后恢复超过期限，保存为超时恢复，不冒充标准限时样本。允许 5 秒网络传输容差，但快照必须在期限内；实际服务端接收用时完整记录。

提交原稿不可覆盖。主动点击 AI 批改才调用现有本机 ChatGPT 订阅 CLI，沿用配置模型与 medium 强度，无 API 付费回退。按任务回应、立场、论证展开、结构、语言控制五维给有原文依据的反馈，集中 2–3 个优先问题和下一步动作；估分一律 `provisional: true`，不是官方成绩或五维简单平均。引用不属于原稿、缺维度或不合规评分会报错，不保存为合格分析。失败或取消不影响原稿。

可从原稿另开练习/修订，保留父稿关联，展开原稿对照；提示使用与 AI 后修订保守标记为有辅助。历次原稿、批改分别保存，学习记录增加“写作记录”入口与导出，不混入普通题目正确率或词汇复习。AI 不自动整篇代写，也不自动更新正式分数或技巧掌握等级。本次不扩展离线词库 APK。

数据实现：`writing.mjs`（事件校验与投影）、`writing-review.mjs`（只读分析契约）、`writing-topics.mjs`（原创练习及官方入口）、`Writing.jsx` / `WritingReview.jsx`（训练与反馈）。

### 题目导航与分类索引

刷题与题目复习均有固定的上一题、保存答案、下一题；切题保留当前浏览器草稿，只有保存才新增正式作答。题目目录按教材、单元或Passage显示题号网格，区分当前题、草稿和已保存状态；小屏默认收起。查看已保存答案不重复计次，需要再次作答时显式重做。题目复习本轮独立，首次进入隐藏旧答案，本轮回看可显示自己刚保存的答案。

2026-10-18 起，刷题按内容避重：题干、全部选项及其顺序一致（阅读还须文章一致）的原题号共享内容身份。仅统一排版差异，不做相似度或近义改写合并；缺正文/选项/文章和不安全 PDF 版式保持独立。进入刷题、恢复停留位置、切题型/单元、上一题/下一题都优先未做内容；保存后仍留在原题看反馈，主动下一题才跳过已做内容。末尾可“继续未做题”回绕，全做完明确提示，不循环把首题当新题。

目录始终保留原题号：“已保存”表示该题号真实作答，“同内容已做”表示另一题号的相同内容已作答；手动点击可只读查看原题，“复习重做”才会进入独立会话再次作答。原 PDF、题号、答案、作答记录与 AI 讲解关联不合并、不删除，不给被跳过的题号创建虚构事件。已有“记忆与背诵”题目复习照常允许重复。仅浏览、草稿、切换和跳过都不算完成。

生词本默认显示密集单词墙，平台启动首页仍为刷题；可切换普通视图并记住偏好，主题/来源目录、编辑、归类、恢复与来源追溯保留。单词墙正面为英文，使用圆润的系统无衬线字体。单击卡片加入选择，重复单击保持选中；双击翻面且不会抵消选中。键盘 Enter 选中、空格翻面。鼠标右键在卡片或词库页面空白处清空选择，也会终止正在进行的框选，但不改记忆标记。按住左键可从卡片、间隙或词墙外的内容区空白处开始拖动，框接触词墙后自动接管，无需先选中文字或卡片；输入框、按钮、侧栏、导航及弹窗保持原生操作。普通框选替换选择，Ctrl/⌘ 框选切换命中词、Shift 追加、Esc 取消当前框选并恢复原选择；靠近窗口上下沿自动滚动，拖动后的 click/dblclick 不触发选中或翻面。也保留悬停/键盘聚焦后的“选择／取消选择”按钮；选中只用绿色卡片边框表示，不显示角落勾选框。支持全部翻回、专注模式，以及舒适/紧凑/极密和列数、行数、卡高、字号自定义。窄窗口自动减少列数，按实际列数分页；长词换行、长释义内部滚动或查看完整详情。

词墙在现有来源/主题/到期/搜索范围上叠加主题、来源、关系类型、记忆状态和多选首字母筛选；同维度多选取并集、不同维度取交集。关系模式保持同组相邻，跨组重复出现的词共享选中/翻面/标记状态，按不同词去重保存；不会为补齐关系组而突破显式筛选。标记后本轮词表留在原位，切换筛选或“刷新词表”后重新计算；不会把未标记当作记得。普通视图与单词墙切换保留筛选。分类词组和今日复习可直接进入词墙。

单个/批量三档标记影响既有间隔复习，但始终是自评，不自动授予掌握等级。一批一次原子保存；同一轮改标不增次，可撤销整次操作。继续实际回忆时使用“开始新一轮”，跨日也自动开启新轮；重试使用相同操作编号，不重复保存。缺释义或已移除词不能标记。学习记录按有效回忆展示，原始改标/撤销在操作日志中保留。

学习记录先按学习日聚合，再按题目或单词查看累计练习及明细，操作日志单列；不把导入和整理数量算成学习量。

### 题中摘词

刷题和题目复习中的“选词”按钮开启摘词模式，拖选题干、阅读文章或选项中的英文单词/短语，再右键即可收入生词本。此模式下点击或拖选选项不改变作答；点击“退出选词”或Esc恢复答题。只接管题目文字上的有效选区，未开启时保留浏览器右键功能；空选区或输入框不用于摘词。已有词提示去重，旧词义和复习历史保留，已移除词可重新收入。

新词无需当场填写释义。生词本“待补释义”可集中整理，详情的“摘词来源”保留题目位置与短语境。收录使用独立vocab_capture事件，不算学习或复习完成。`useWordCapture.js`负责页面交互，`shared/capture-word.mjs`统一前后端词形校验。PDF原题区域只在选词模式按需添加PDF.js文字层，保留原渲染与定位；没有文本层的纯扫描图片不做自动OCR，界面会提示不能选词。资料库独立PDF阅读器不在本次摘词范围。

### 词汇分类与关联

生词本的“分类与关联”入口提供主题浏览、近义词、反义词和形近词检索。初始数据在 `vocab/relations.json`，运行时叠加用户主题与关系事件；数量以实际数据为准。主题根据现有中文释义和明确词表提出建议，支持多主题；没有把握的词保留待分类。单词分类可以手动覆盖或恢复自动建议，不把覆盖率当成学习掌握度。

关系组支持新增、编辑、移除及恢复，成员从已有生词本选择；移除词组不删除单词。近义关系仅限说明中的义项，不能自动判定SE等价。初始辨析分为已查词典与待核草稿，编辑后标记自己整理。词组详情提供逐词词典入口。“对照记忆”先隐藏用法，揭晓不写学习证据；“背诵这一组”及“背诵当前词表”接入多阶段学习。

`platform/server/word-relations.mjs` 独立负责事件校验、主题和关系投影、拼写候选生成。形近候选按编辑距离生成并缓存，不视作近义词、不自动入组；确认后可收录。关系与分类修改全部写追加事件，使用原有同步、刷新和历史机制，旧词义、掌握状态与训练记录保持原始证据。

### 模块

“记忆与背诵”现为每日复习入口，汇总到期词数、到期题数、今日已完成与实际复习次数，并展示未来7天当前已排定的量。任务支持按类别、到期状态和词义检索，20项分页，逐项查看累计次数、下次日期和最近20次历史；完整事件仍保留。默认单词每轮10个（上限20）、题目每批10道，逾期积压保留，可以分批完成。待首轮单独列出；缺释义的词可在任务行补充。

单词一轮按英→中两遍、补全字母、中→英推进。认义使用已有释义作选项，排除已知关系词、重复和明显重叠释义；无法构成可靠选项时明确采用自查，不机械核对中文自由回答。每次反馈立即保存为vocab_drill，错误排回本阶段队列后方，释义和选项以开轮快照为准。中断可从事件恢复；本词全部阶段通过才追加一次vocab_recall，多次重试不重复结算。首次认义困难、首次拼写困难和全程顺利分别影响下次安排，纠正不会抹去错误。主动提取与间隔学习有研究支持，但四阶段、批量及固定天数是可调整设置，见SCHEMA中的依据。

普通背词、分类词组背诵和普通做题都会自动更新复习安排。重做入口隐藏旧答案、历史AI讲解和旧作答，提交后显示答案、反馈及下一次日期，避免靠刚看到的答案完成复习。组内跳过不记完成；忘记后稍待10分钟重新进入到期队列，无需手填题号。

排期规则与计数边界详见SCHEMA的间隔复习章节。`spaced-review.mjs`负责纯投影，`legacy-review.mjs`只读接入明确作答的旧题；初次接入不会写几百条虚构学习事件。相同Git事件和时区在其他设备得到同一排期，日期随当地学习日刷新。检查覆盖跨日、同日重复、忘记后再练、答案后来补充和旧证据去重；真实训练库不写测试数据。

- `platform/server/store.mjs`：旧数据适配、事件校验和投影；新增模块只扩展事件类型，不覆写累计文件。
- `platform/shared/word-session.mjs`：前后端共用的阶段顺序、拼写核对、错误重练及轮次结算规则。
- `platform/server/index.mjs`：本地HTTP、PDF流、同源检查。
- `platform/server/sync.mjs`：有限路径的Git同步，串行写入。
- `platform/server/question-bank.mjs`：从默认PDF提取位置和作答方式，按资料文件变化自动重建本地缓存；读取历史训练和平台作答推荐下一题。
