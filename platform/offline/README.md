# 单文件离线版

复用原平台 React 页面、事件验证、词汇轮次和间隔复习投影。单个 HTML 包含运行代码、当前仓库的文本学习数据、预先解析的题目索引和 PDF 阅读器；打开后无需 HTTP 服务、Termux、网络托管或 AI 接口。在线平台继续使用原来的入口与配置。

## 构建

在安装原项目依赖后运行：

```bash
node platform/offline/build.mjs --out /absolute/path/GRE-platform-offline.html
```

需要三份原版教材位于 `materials/files/`。也可传 `--pdf-dir /absolute/path/pdfs`，其中依次放 `tc.pdf`、`reading.pdf`、`quant.pdf`。`--import /absolute/path/answers.json` 可接入旧单文件题包的真实作答或本离线版的导出记录。导入按 UUID 去重，并保持原始提交时间；题目内容冲突或同一编号内容不一致时停止。

构建输出含个人学习数据，请在本地或用户自己的文件存储中保存；不要把生成的 HTML 和测试导出提交到公共仓库。构建器只读取训练数据，不追加学习事件。测试写入临时目录或隔离浏览器。

## 功能与边界

- 保留刷题、生词本、分类与关联、多阶段记忆复习、学习记录；沿用原有判分和复习规则。新事件在浏览器内处理，不调用 `/api` 网络端点。
- 浏览器缓存仅作辅助。每次学习后下载 JSON 或“带记录的 HTML”，确认手机确实保存文件。缓存不可用时会显示提示，仍可在当前页面作答并导出。
- JSON 包含离线新增事件、对应题目与选项、草稿和轮次缓存。重新导入同一份文件不会增加次数；原平台快照中的事件不重复输出。
- 带记录的 HTML 可在新的浏览器会话中继续。普通保存不会改写手机上的原 HTML。
- 已可靠抽取文字的 TC、SE、Reading 可直接使用。数学、图表及特殊排版题保留原平台的 PDF 定位方式，需要在资料库手动选择对应原版 PDF；用 SHA-256 核对教材，防止页码错位。PDF 不上传、不嵌入备份，重新打开后需重新选择。
- 沿用原解析器；索引数可能少于教材标题标称数。当前三本解析出 2002 道填空/等价、893 道阅读和 847 道数学定位，共 3742 道；其中 2790 道原题具有可靠文字布局。其余需要 PDF。
- 已有 AI 讲解可查看；新讲解通过导出文件发回聊天完成。离线版不会调用或升级模型；在线平台继续保持 `gpt-5.6-terra`、`medium`。讲解仍要求完整题干翻译，逐项覆盖核心义、语境义、翻译、选择或排除依据，SE 说明完成句等价性。
- 离线导入、保存或导出都不会自动同步 GitHub。之后由用户提供导出文件再进行合并。

## 实现

`OfflineApp.jsx` 复用原组件。构建器把前端 API 适配到浏览器内的 Store，并将节点文件访问适配到内存文件映射；`Store` 本身的规则保持共用。源码数据仅解析一次，投影按事件变化和分钟边界复用；每分钟/返回页面时更新复习日期，不每五秒读取全库。静态包不进行外部资源请求；PDF 使用本机选择后生成的 Blob URL。

原网页的草稿存储经构建适配到内存与缓存双层接口，缓存被禁用时仍可导出。文件导出不等于系统保证下载成功，界面会要求在手机“下载”目录确认。
