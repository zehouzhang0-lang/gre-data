# Issue 写作首版：目标3.5，先分步训练

用户明确确认AW先以3.5为目标，其他讨论项按默认选项，并授权实现预览。profile仅更新目标，不更新当前分数、scores或mastery；仍无用户真实作文样本，不能预设个人弱项。此记录取代之前“尚未授权开发”的讨论状态，但保留此前原记录。

## 首版范围

- 电脑学习平台侧栏新增写作训练，默认提纲，也可单段/整篇与30分钟Issue限时。没有旧Argument模式，不扩展手机APK。
- 六道明确标注“教练原创、非ETS真题”的入门练习，完整英文题干与任务要求、可折叠中文；提供ETS题库获取入口与手动输入。官方题库尚未整体导入。
- 每次编辑本浏览器自动保存，提交前明确全文完成声明；截止冻结，绝对倒计时跨刷新，断网保留同一冻结快照重试。正式保存只发生在服务端成功响应后；草稿不经Git同步，可导出文本。
- 原稿、修订、AI点评独立追加，按父稿并排对照；局部修订只从真实原文片段开始；继承提示使用。学习记录单列写作，不污染客观题正确率/复习排期。
- 显式AI按钮复用现有Codex订阅、模型与medium强度。五维反馈、2–3个优先问题、局部建议与下一次动作；完整作文估分始终provisional，提纲/单段/未完成全文强制无整体分数。AI引用必须对应原稿，不能拼接或假造引文。

## 已知边界

本地限时是练习工具，不是监考防作弊证明；关闭浏览器后超时恢复不会冒充标准限时样本。AI需网络和订阅额度，输出不合规时保留原稿并提示重试，不能保证每次调用成功。未提交草稿只在本浏览器，不在两设备或标签同时编辑同稿。此轮未产生可用于诊断用户能力的真实作文证据。
