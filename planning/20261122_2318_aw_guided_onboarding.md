# AW入门与逐句引导

用户自报很长时间未接触英语写作，希望先快速了解AW组成、时长、问题类型及与雅思写作的直观比较，并请求教练一句一句带写。自报没有具体起止时间，不推断曾有何种写作水平，也不从雅思项目读取个人数据。当前尚无用户作文或可验证能力基线。

## 本轮训练方式调整

- 本轮先做不计时入门和逐句引导，暂不执行上一轮派发的25分钟独立段落计时；未将原计划标记完成或失败。
- 继续使用已有原创题 `coach_issue_feedback_01`，来源为 `platform/server/writing-topics.mjs`，材料 ID 为 `coach_issue_exercises`。
- 首个动作只需用户用中文或英文表达自己的立场与一个直接理由。下一轮据其意思引导一句英文立场句，再逐句展开理由、例子和解释。
- 每轮优先处理一个最影响意思的问题，让用户尝试修订后再继续。必要时提供词语或句框；教练示范明确标注，不冒充用户原稿。
- 后续记录分别保留用户首次表达、教练提示和用户修订，注明guided practice和实际辅助。实际用时尚未知，不能写成25分钟。
- 本轮指导稿不计入冲刺v2的三次独立全文，后续独立训练按新样本调整难度。本次不改全科排程或每日快照，不生成完成事件、作文提交、评分或mastery成功证据。

## 官方核对与解释边界

核对日期：2026-11-22，Asia/Kuala_Lumpur。

- [ETS AW概述](https://www.ets.org/gre/test-takers/general-test/prepare/content/analytical-writing.html)：现行任务为一篇Analyze an Issue，30分钟内审题、构思、成文与检查；电脑编辑器无拼写和语法检查。不要求专门学科知识。
- [ETS Issue任务](https://www.ets.org/gre/test-takers/general-test/prepare/content/analytical-writing/issue.html)：题目观点与具体任务要求共同决定作答；可能要求讨论成立条件、回应反方、比较两观点、同时评价主张与理由、分析政策后果。四段式只是教练起步框架。
- [ETS评分描述](https://www.ets.org/gre/test-takers/general-test/prepare/content/analytical-writing/scoring.html)：3.5–4分要求回应具体任务，以相关理由或例子支持观点，组织基本清楚、表达可理解，允许部分错误。
- [IELTS官方写作描述](https://ielts.org/cdn/ielts-guides/ielts-writing-band-descriptors.pdf)：Task 2第6档描述中的切题立场、整体连贯和大体可理解的表达，可帮助解释写作质量。与AW要求只有部分重叠，不构成量表等值。

本次查阅未发现GRE AW与IELTS Writing官方换算依据，不给出“AW3.5等于雅思某分”的结论，也不利用用户自报久未写作推算当前分数。
