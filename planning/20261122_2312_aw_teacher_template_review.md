# 老师 Issue 模板：接收摘要与使用方法

用户提供老师的写作参考资料，要求教练消化，后续训练据此接续。资料含两组可替换的开头、同意段、反对段、结论，以及连接词和论证词汇。其主要思路是部分同意、说明成立条件、讨论局限、给出综合判断。这是外部教学材料，不是用户作文、官方范文或已完成训练。仅保存自写摘要及核验结果，原始全文保留在用户本次聊天消息中。

下列为教练根据这些要求对本材料的适配判断，不是 ETS 对此模板的评价或分数保证。

## 后续使用约定

1. 保留开头—主体—结尾的组织功能，以及主张—理由—具体例子—解释的段落链。四段可以作为起步框架，段数随题目及展开需要调整。
2. 先确定实际立场再选择句式，不固定每题部分同意、正反各半或折中。结尾必须说明自己的优先判断或适用条件；不能只说双方都有价值。
3. 题目本身没有绝对化时，不直接写它极端或忽略关键因素。使用这类判断前，要指出原题的具体表述、未考虑的条件，以及该条件如何影响结论。反驳必须准确针对题目，不扩大原主张。
4. 压缩泛泛宣布问题复杂、将展开分析、例子有说服力的句子；把篇幅用于具体理由、过程、结果和支持关系。模板中的占位内容必须承担实质分析。
5. 每主体先展开一个例子，解释事实如何支持理由，再决定是否增加第二个。例子数量不设机械配额；第二个例子应增加新的论证作用。
6. 题干后的任务要求决定展开重点。涉及比较两种观点、评价主张与理由或政策后果时，应逐项回应，不能用固定正反段取代具体要求。
7. 连接词和表达可按需要使用；不把词汇复杂程度或记住模板作为能力证据。词表中文义为待按具体句子核实的参考，本轮未逐词核验。
