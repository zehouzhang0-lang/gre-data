# 写作目标讨论：尚无作文基线

用户自报：没有尝试过 GRE 作文；询问在 Verbal 目标150的情况下，作文需要多少分。

- Verbal 与 Analytical Writing 分开评分，不能将V150换算为AW分数；写作不计入V或V+Q合计。
- 教练建议暂以AW4.0为训练目标，待用户确认、目标申请项目要求与独立作文样本后调整。不是当前水平估计、成绩保证或通用录取线。
- 4分评分描述重点为回应任务、立场明确、相关理由/例子、结构清楚与可理解的英文表达，允许一定错误；不以生僻词数量、固定篇幅或模板替代论证。
- 尚无作文，不能给完整暂定评分。建议之后先完成一篇独立限时Issue用于诊断；本次未开始或完成该练习，不创建训练事件。
- 功能建议继续保持待确认：考虑在写作模块增加新手审题/提纲入口，并与独立限时实战分开。未授权开发，不改平台代码。
- 原档案V+Q目标320；若V目标为150且合计目标不变，Q须170。尚未确认最终分科组合，不更新profile目标或当前分数。
- 待确认申请专业/项目，以及是否存在写作最低分要求。
