# 词库整理 · 2026-09-16

本次整理 **357 个词条**：补齐 **215 个缺释义词**（开始时 211 个，加上整理期间新摘录的 molecular、exploit、forestall、stave off），核验手写 **142 个不重复词条／短语**。其中手写词新增 **139 个**，已有的 fetter、permeate、regurgitate 合并来源。另将 botch up 作为 botch 的搭配收录，合并同页重复的 extempore。

每词补充词性、中文核心义、搭配、语体或褒贬色彩、简短辨析、词典链接及核验日期。释义依据实际读取的 Merriam-Webster 官方词条；the least bit、surrogate 的补充证据包括 Cambridge 官方检索节选，来源字段明确记载正文访问受限，未冒称直接打开成功。中文释义为归纳，搭配为教学自拟。

[ETS 的 Verbal 指引](https://www.ets.org/gre/test-takers/general-test/prepare/content/verbal-reasoning.html)要求根据实际上下文判定词义，Sentence Equivalence 要看完成后的整句含义。因此本批保存词典核心义和用法辨析，不把第三方词表或自行整理的中文释义标为 ETS 官方答案。具体题目仍需结合原句核验。

## 本次修正与易混点

| 项目 | 整理结果 |
| --- | --- |
| will-disposed、mecabre | 规范为 well-disposed、macabre，原手写形式留档 |
| abruptly | 副词，不是形容词 |
| per se | 本身；就其本身而言，主记副词短语 |
| estimable | 主记值得尊敬、赞赏；“有价值”不可随处替换 valuable |
| behemoth | 主记名词“庞然大物”，可作定语 |
| least bit = a little bit | 分开收录；not the least bit 是“一点也不” |
| repercuss、repercussion | MW 所核动词义为击退；名词可指间接或未预料的后果、反响 |
| saccharin、saccharine | 糖精是名词；甜腻、感伤过度是形容词用法 |
| regimen、regiment | 规律方案；军队的团／严格管制 |
| vocation、avocation | 职业或使命感；业余爱好 |
| symbiosis | 生物学广义不只包括双方互利，避免机械记成“互惠” |
| exploit | 有效利用与剥削须依对象、语境区分；名词另有功绩义 |

## 分类与关联
