## 重点订正

- barring：本页“除……外”是介词。
- teetotalism：是完全不饮酒的原则或实践，不是形容词，也不必指政府禁酒政策。
- indigenous：纠正手写拼写；本土来源与 endemic 的地方特有、持续存在有区别。
- arguably：有理由认为，保留判断余地；nominal 同时留意名义上的、微小的两义。
- tempers → temper：来自第143套第2节难题第1题选项，相关动词义是缓和；原始摘词保留。
- brag 的形容词义及 asunder 的形容词用法有词典依据，保留但把常用义放在前面。

## 成组辨析

- **协调与不协调**：congruity / incongruity。反义限定于组成部分彼此吻合或事物适合情境的程度；不是说所有细节必须相同。 例句为教学自拟。
- **evasive 与 elusive**：evasive / elusive。两词拼写相近且都可涉及躲避。evasive 常描写有意回避的动作或答话；elusive 侧重某物难以被抓住、找到或理解。 例句为教学自拟。
- **证据含糊与足以定论**：equivocal / conclusive。反义仅限 evidence、results 等语境中结论的明确程度；不把 equivocal 的所有人格或言辞义都与 conclusive 对立。 例句为教学自拟。
- **coherent 与 cogent**：coherent / cogent。两词可形容论述，分别检查内部是否连贯、理由是否有力。表达连贯不保证证据充分。 例句为教学自拟。
- **闷闷不乐与伤感忧郁**：glum / melancholy。近义限于低落情绪。glum 常表现为阴沉不乐的神色；melancholy 还可含沉思伤感，或修饰令人伤感的艺术作品。 例句为教学自拟。
- **和蔼与粗鲁**：affable / churlish。反义限定在待人的态度：affable 让人易于亲近交谈；churlish 常指无礼、不友善。 例句为教学自拟。
- **温和与易怒**：mellow / irascible。反义限定于脾气或待人态度；mellow 的酒味醇厚、声音柔和等义项不在此对应。 例句为教学自拟。
- **礼貌与相互礼让**：comity / civility。两词共享文明友好的范围。civility 更聚焦言行有礼；comity 更常强调群体间的和谐与相互尊重，另有法律、国际关系中的礼让义。 例句为教学自拟。
- **幼年的与幼稚的**：puerile / juvenile。近义只在批评不成熟行为时成立。juvenile 还能中性描述年龄与未成年群体；puerile 常带幼稚可笑的讥评。 例句为教学自拟。
- **征求、恳求与乞求**：solicit / entreat / supplicate。共同点是请求；用语姿态不同。solicit 可正常征求意见，entreat 强调恳切，supplicate 更突出谦卑或祈求。 例句为教学自拟。
- **改善处境与平息怒气**：ameliorate / mollify。近义仅在使不良状态缓和这一方向。根据宾语选择：ameliorate 常对处境、痛苦或不良影响，mollify 常对生气的人或情绪。 例句为教学自拟。
