## 词形与释义核对

- **profund → profound**：手写作 profund；结合“深刻的、深邃的”等释义，规范为 profound，沿用已有词条。
- **preeminent**：同页右侧划掉的重复拼写不另计词。
- **plethora**：保留手写过剩义，同时补明词典所载中性大量义。
- **cosilience → consilience**：手写 cosilience 缺少 n，按字形与释义校正为 consilience；保留一致义，并补明不同归纳结论相互印证与跨学科融通的常见学术语境。
- **discont → discount**：照片词形近似 discont，依据“折扣／忽视／低估”释义校正为 discount；忽视等义归入动词，不归形容词。
- 重拍页沿用昨日的 `diciple → disciple`、`crastfallen → crestfallen` 等校正；背景露出的词和划掉的重复拼写不另计。
- **compulsory**：义务教育中的“义务”指依法必须履行，不是自愿；名词“规定动作”用于比赛语境，常用复数 compulsories。
- **segregate**：名词指被分离者或分离出来的个体，并非专指实施隔离的人；社会隔离和遗传分离需按语境区分。
- **consilience**：学术语境常指从不同数据或领域得到的归纳结论相互吻合，也可指跨学科融通或不同群体合作。词典另收录较宽泛的一致、吻合义，照片中的“一致”有依据；需结合具体搭配判断。
- **facile**：修饰论点或答案时常贬指把复杂问题说得过于简单；修饰表达或技巧时可褒指流畅自如；情感义指来得太容易而显得不真诚。
- **agog**：通常作表语，表示对某事极感兴趣或惊奇；可与 with、over、about 等连接，不能只释为急切地。
- **discount**：论证语境常指降低某种说法或因素的可信度、重要性；财务语境另有贴现和预先计入未来因素的含义。

## 关联辨析

- **pithy / terse**：pithy 强调表达简短而有实质内容；terse 强调简练，有时显得简短生硬。不能把所有简短回答都理解为言之有物。 关系只适用于所述义项，不代表 SE 整句自动等价。
- **superfluous / superfluity**：superfluous 是形容词，说明超过所需；superfluity 是名词，可指过剩的数量或多余之物。 关系只适用于所述义项，不代表 SE 整句自动等价。
- **guile / beguile**：guile 是名词，指欺骗性的狡诈；beguile 是动词，可指诱骗，也可指吸引或愉快地消磨时间，后两义不必含欺诈。 关系只适用于所述义项，不代表 SE 整句自动等价。
- **riddle / conundrum**：两词在令人困惑的问题这一名词义上可重叠。riddle 还可指供人猜解的谜语；conundrum 常指复杂难题或困境，其双关谜语义带古旧色彩。 关系只适用于所述义项，不代表 SE 整句自动等价。
