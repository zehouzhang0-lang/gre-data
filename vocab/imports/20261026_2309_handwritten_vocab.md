## 词形与释义校正

- **glid → glide**：照片写作 glid，结合“滑行、滑翔”规范为 glide。
- **algae → alga**：手写 algae 为 alga 的复数，按词元归入已有 alga；保留本次原始词形，不改已有词条或记录。
- **phytoplankton**：手写“浮游生物”范围偏宽，规范为“浮游植物”。
- **provisional**：手写名词“临时执照”改在搭配说明中解释；独立名词保留已核实的“临时邮票”。
- **concerted**：手写动词标记不另作 concerted 的原形动词词性；该形式作动词时归属于 concert。
- **onetime**：手写把“一次”并列在副词下；按词典将“一次性的”归入形容词，副词保留“从前”。
- **jury**：手写动词“鉴定、评审”补充展览作品的适用范围；“临时的”限定为应急拼凑。
- **parish**：手写最终改为 n.；按词典明确归为名词，不保留被划掉的形容词标记。
- **epithet**：划去的先前拼写不另建词，采用最终写出的 epithet。
- **hermetic**：手写名词“炼金术士”不作为 hermetic 的义项；保留有依据的相关形容词义。
- **buck**：手写的“完全的”应在 buck naked 等搭配中标为副词“完全地”，非普通形容词。
- **conciliate**：手写词形近似 cociliate，按安抚与和解语义及标准拼写整理为 conciliate。
- **stoic**：手写“禁欲主义的”改为克制情绪、坚忍义；哲学专名规范为“斯多葛学派的”。
- **woven**：woven 不另录重复的动词释义；因词典另有独立形容词和名词用法，与 weave 分开保留。
- **vernacular**：vernacular 左侧被划去的草稿不另计；按清晰的完整词形保留 vernacular。
- **Sanskrit → sanskrit**：系统词条键按既有规则统一为小写 sanskrit；标准英语写法 Sanskrit 保留在说明中。
- **moribund**：将笔记中名词标记下的“垂死/濒危”统一归入有依据的形容词义，不新增无依据的名词。
- **mortify**：笔记里的“抑制”需限定为克制肉欲、禁欲修行；日常常见义是让人非常难堪。
- **blithe**：轻松愉快可为正面；对风险或他人毫不在乎时通常含批评。
- **stalemate**：可用于谈判或冲突无法推进，也有国际象棋中的专门含义。
- **misfeasance**：词义重点是本可合法履行的行为被以不当或违法方式执行，也可涉及不当动机；不要仅与 malfeasance、nonfeasance 一律记为“渎职”。

## 关联辨析

- **provincial / parochial**：provincial 和 parochial 都可批评眼界受地方经验局限；各自的省或教区本义不包含这种贬义。 关系只适用于所述义项，不代表 SE 整句自动等价。
- **machinate / machination**：machinate 表示策划阴谋；machination 指密谋或阴谋诡计，不能忽略词性互换。 关系只适用于所述义项，不代表 SE 整句自动等价。
- **conduce / conducive**：conduce 是动词，conducive 是形容词；两者通常与 to 搭配，表示促成某种结果，不一定是正面结果。 关系只适用于所述义项，不代表 SE 整句自动等价。
- **placate / appease / conciliate**：三者均可涉及减少敌意；placate 侧重使人消气，appease 可含以让步满足对方，conciliate 侧重争取好感或调和。 关系只适用于所述义项，不代表 SE 整句自动等价。

- **vernal / venal / vernacular**：vernal 指春天或青春；venal 指可被收买或与贿赂有关；vernacular 指本地语言或地方表达方式。词形相近而语义不同。 关系只适用于所述义项，不代表 SE 整句自动等价。
- **flimsy / tenuous**：flimsy 常指论据或借口缺乏可信度；tenuous 常指联系或支持证据很薄弱。这组只比较抽象的薄弱义，不把所有材料或稀薄义混同。 关系只适用于所述义项，不代表 SE 整句自动等价。
