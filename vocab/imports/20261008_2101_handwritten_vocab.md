## 易混与近义词辨析

- **contrite / penitent**：两者都表示为过错而后悔；penitent 另可作名词“悔罪者”。remorse 是表示感受的名词。
- **pensive / musing**：共同义为沉思；pensive 可带忧郁，musing 可作名词思绪。
- **surpass / trump**：仅在动词胜过义接近；trump 另有王牌名词义。
- **requisite / exquisite**：requisite＝必需的；exquisite＝精美、精湛的，或感觉强烈的。
- **curt / terse / laconic**：curt 通常简短得不礼貌；terse 可精练或生硬；laconic 强调寥寥数语。taciturn 则形容一贯沉默寡言的性格。
- **accustom / inure**：accustom 通用；inure 特别指习惯困难、不愉快的刺激。两者常搭配 to。
- **garish / garnish**：garish 是俗艳刺目的形容词；garnish 常作装饰动词或配饰名词。
- **permanent / impermanent**：永久或持续稳定，与非永久、暂时相对；按对象讨论时间范围。
- **impede / trammel**：impede 强调阻慢进度；trammel 强调限制自由活动，且另有名词义。
- **recalcitrant / obstinate / defiant**：recalcitrant 抗拒管束；obstinate 固执不听劝；defiant 公然挑战或反抗。
- **unalloyed / unadulterated**：都可表示未掺杂、十足；色彩取决于所修饰的是喜悦、胡说还是其他事物。
- **adulterate / contaminate**：adulterate 常指掺入低劣物质、掺假；contaminate 泛指污染，可由接触或混入发生。
- **cunning / crafty**：在狡猾义相近，也可能赞叹机巧；是否欺骗须由语境决定。
- **comparable / analogous**：comparable 可表示适合比较或相当；analogous 强调可据某些相似点作类比，不保证完全相同。
- **insipid / vapid / bland**：三者在乏味义接近；bland 的温和、清淡义可中性，insipid、vapid 评价内容时通常贬义。
- **impede / expedite**：在进度语境中分别指阻慢和加快；均可为及物动词。
