## 词形与释义校正

- **wick**：灯芯义归入名词；另补词典所列吸走液体的动词义。
- **wicked**：手写“恶人”对应 the wicked，作为形容词集合用法说明，不误列为普通可数名词。
- **goade → goad**：手写近似 goade，结合刺棒及驱使义规范为 goad。
- **reakon → reckon**：手写 reakon 校正为 reckon。
- **flagrant**：依照片最后保留词形归一为 flagrant；划掉的重写不重复计词。
- **slew**：区分独立词 slew（大量；转动）与 slay 的过去式 slew；手写杀戮仅作为词形说明保留。
- **petulant**：采用照片下方最终词形 petulant；右侧划掉的拼写不另立词。
- **alacrity**：将笔记单纯速度义扩充为“欣然、爽快地行动”。
- **competing**：手写既写动词又写形容词；本词按 Oxford 独立形容词条目整理，competing 的动词分词用法另属 compete 的词形。

- **demolish / obliterate / extirpate**：只比较消除、毁坏义。demolish 常指拆毁建筑或推翻论点；obliterate 强调彻底毁灭或消除痕迹；extirpate 强调连根清除。 关系限于上述义项，不代表 SE 整句自动等价。

- **nascent / budding**：nascent 指刚开始存在或形成；budding 可指初露头角，也可指植物萌芽，不把全部义项等同。 关系限于上述义项，不代表 SE 整句自动等价。
- **inconstant / mercurial**：inconstant 强调不稳定或不忠贞；mercurial 强调情绪、性情迅速而难预测地变化。 关系限于上述义项，不代表 SE 整句自动等价。
- **inimical / baneful**：inimical 常与 to 连用，也可表示敌意；baneful 表示造成伤害或毁灭，只在有害的作用上相交。 关系限于上述义项，不代表 SE 整句自动等价。
- **callous / heartless**：callous 侧重对他人的痛苦麻木不仁；heartless 侧重没有同情心、冷酷。 关系限于上述义项，不代表 SE 整句自动等价。
- **besiege / beleaguer**：besiege 可指军事围攻或要求纷至沓来；beleaguer 可指围困或持续受问题困扰，需结合具体宾语。 关系限于上述义项，不代表 SE 整句自动等价。
- **precede / predate / antedate**：precede 可指时间或次序在先；predate、antedate 的此处共同义是存在或发生得更早。predate 的捕食义、antedate 的倒填日期义另算。 关系限于上述义项，不代表 SE 整句自动等价。
