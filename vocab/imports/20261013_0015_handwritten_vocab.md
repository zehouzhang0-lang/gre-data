- **rapacious / avaricious**：均可描述贪欲；rapacious 更突出强取豪夺，avaricious 更突出渴求财富，不能把所有语境都当成等价。 按具体义项辨析，不凭近义词关系直接判定 SE 整句等价；搭配为教练自拟。

- **rattle / disconcert**：仅比较心理义：rattle 强调慌乱失措，disconcert 强调被打乱而不安困窘；rattle 的声响义不在此组。 按具体义项辨析，不凭近义词关系直接判定 SE 整句等价；搭配为教练自拟。
- **muster / rally**：仅比较聚集人员或支持义；muster 还可鼓起勇气，rally 还可指恢复精神、价格或形势。 按具体义项辨析，不凭近义词关系直接判定 SE 整句等价；搭配为教练自拟。
- **comply / flout**：限定规则或要求语境：comply with rules 为遵守规则，flout rules 为公然蔑视、不遵守；注意 comply 常接 with。 按具体义项辨析，不凭近义词关系直接判定 SE 整句等价；搭配为教练自拟。
- **apposite / incongruous**：限定言论、举例与情境的适合程度：apposite 贴切，incongruous 不协调、不相称；并非所有义项都互为反义。 按具体义项辨析，不凭近义词关系直接判定 SE 整句等价；搭配为教练自拟。
- **duplicate / duplicity**：复制／副本 vs 欺骗／口是心非；沿用平台既有形近词组。
- **thrift / miserly / avaricious**：节俭（通常褒义）／吝啬不肯花钱／贪求财富；不是三个同义词。
- **reiterate / recapitulate**：重申、再次说 vs 概括重述要点；概括与重复不可机械互换。
