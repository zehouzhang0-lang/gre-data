## 易混与近义词辨析

- **emulate / simulate / imitate**：imitate是模仿；emulate常含力求达到或超过榜样；simulate是模拟或假装。
- **stimulate / simulate**：stimulate刺激、激发；simulate模拟、假装，注意中间的t。
- **temporal / temporary / contemporary**：temporal表示时间的，也可指世俗的；temporary表示暂时的；contemporary表示同时代的或当代的。
- **restless / restive**：restless侧重无法安定；restive侧重因约束而焦躁或不服管束。
- **transient / ephemeral / temporary**：仅比较持续时间短：ephemeral强调转瞬即逝，transient强调不会持久，temporary强调临时安排。
- **arcane / impenetrable**：仅比较难懂义；arcane偏少数内行才知，impenetrable偏无法看透或理解。
- **encomium / panegyric**：两者均可指正式赞颂；panegyric常带盛赞或颂文色彩。
- **subterfuge / chicanery / deception**：subterfuge偏为隐瞒目的而用的计谋；chicanery偏耍诈与诡辩；deception是较宽泛的欺骗。
- **partisan / tendentious**：仅比较偏袒一方的表达；partisan偏党派或阵营立场，tendentious偏带有刻意倾向性。
- **marginal / peripheral**：仅比较不处于核心的重要性义；marginal另有微小、勉强义，peripheral另有外围的空间义。
- **cloak / camouflage**：仅比较掩盖真实情况；cloak偏遮掩，camouflage偏使对象与环境融合而不易辨认。
- **harbinger / portent / precursor**：harbinger为先兆或预示者；portent常是重大或不祥预兆；precursor是先行者、前身或前兆。portent是名词。
- **judicious / prudent**：judicious强调判断明智；prudent强调谨慎考虑未来后果。
- **intrinsic / inherent**：intrinsic侧重事物自身本质；inherent侧重某性质与对象不可分，常用inherent in。
- **forestall / thwart**：forestall强调抢先行动以阻止；thwart强调使计划或企图受挫，不必预先发生。
- **excoriate / denounce**：excoriate是严厉斥责；denounce常指公开谴责，也可指告发。
- **obnoxious / odious**：obnoxious常指冒犯、惹人厌烦；odious强调可憎、令人憎恶，程度通常更强。
- **culpable / blameless**：仅比较是否应受责备；culpable有责任或过失，blameless没有应受责备之处。
- **exultant / dejected**：exultant常因成功而欢欣；dejected常因失望而沮丧。
- **converge / bifurcate**：在方向或结构变化中，converge趋于汇合，bifurcate分成两支；并非所有抽象语境都直接相反。
- **perplex / bewilder / befuddle**：都可指使困惑；bewilder偏不知所措，befuddle偏思维混乱，perplex偏问题令人费解。
- **command / commend**：command常指命令、指挥；commend常指称赞、推荐。command respect是赢得尊重，不是命令尊重。
- **agony / anguish**：两者均可指极度痛苦；agony常用于强烈身体疼痛或精神煎熬，anguish尤其强调严重精神痛苦。
