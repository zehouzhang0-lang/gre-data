## 重点订正

- 第 1 页 · **self-regard**：词性为名词；可指自尊或对自身利益的关注，过度时含自负之意。
- 第 1 页 · **durable**：核心为形容词耐用的；耐用品常写作复数 durables 或 durable goods。
- 第 1 页 · **dispassionate**：强调不受个人情感左右、客观冷静，不等于冷酷无情。
- 第 2 页 · **anthropogenic**：规范拼写 anthropogenic；指由人类活动造成，不一定指有意制造。
- 第 2 页 · **expurgate**：规范拼写 expurgate；删去文章中不宜或冒犯性的内容，不是 expel（驱逐）。
- 第 2 页 · **reparation**：规范拼写 reparation；补偿或赔偿，战争赔款常用复数 reparations。
- 第 2 页 · **peruse**：词典同时收录仔细阅读和浏览翻阅；不能把浏览义一概判错。

- 第 2 页 · **lucubration**：规范拼写 lucubration；指费力研究或其论述成果，不宜只记成一般的刻苦。

## 易混与近义词辨析

- **abash / aback / abate**：abash 使窘迫；aback 是副词，常见 be taken aback；abate 是减弱或减轻。
- **vain / vein**：vain＝徒劳的、自负的；vein＝静脉、矿脉或风格倾向。
- **melodious / malodorous**：melodious 描述声音悦耳；malodorous 描述气味恶臭，也可有不正当的比喻义。
- **pique / arouse**：在激起兴趣、好奇义相近；pique 另有冒犯自尊而恼怒义，arouse 还可唤醒。
- **expel / oust / exile**：expel 逐出组织或排出物质；oust 强调赶下职位或逐出位置；exile 动词强调放逐离乡。
- **expatriate / expurgate**：expatriate 与侨居国外有关，不必是流放；expurgate 是删去文本中的不宜内容。
- **molder / crumble**：molder 常指逐渐腐朽；crumble 常指碎成小块，也可比喻信心、政权瓦解。
- **lucid / limpid / pellucid / transparent**：只在表达清楚义接近；lucid 也指头脑清醒，后三者可用于透明材料；transparent 还可评价借口显而易见。
- **cryptic / enigmatic / recondite**：cryptic 常指表达像谜；enigmatic 常指人或事难以看透；recondite 常指专门、冷僻而深奥的知识。
- **lucid / cryptic**：在表达语境中，lucid 清楚易懂，cryptic 隐晦难解；并非所有义项都互为反义。
- **munificent / magnanimous**：munificent 尤重金钱礼物的大方；magnanimous 尤重宽宏大量、不计较，不能在所有语境互换。
- **engaging / engrossing**：engaging 常含讨喜、迷人；engrossing 强调吸引全部注意力。
- **dreary / tedious**：dreary 常伴阴郁、沉闷感；tedious 常因冗长或重复而乏味。
- **wearing / tiring**：两者均可形容造成疲劳的事情；wearing 常兼有精神消耗或烦累。
- **scathe / excoriate**：仅在严厉谴责义相近；两者另有伤害义，scathe 较少用，scathing 形容词更常见。
- **mar / taint**：mar 是损害完美或愉快程度；taint 是污染、玷污，尤可用于品质或声誉。
- **artful / shrewd**：artful 强调巧妙技巧且可能含欺骗；shrewd 强调敏锐判断，不必不诚实。
- **nullify / abrogate / abolish**：nullify 使无效或抵消；abrogate 常正式撤销法律或条约；abolish 常废除制度或惯例。
- **comprehend / comprehensive**：comprehend 动词理解，亦可包含；comprehensive 形容词全面的，不等于易懂的。
- **resolution / resolute**：resolution 名词决心、决议、解决或分辨率；resolute 形容词坚定的。
